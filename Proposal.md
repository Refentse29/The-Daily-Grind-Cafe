# Web Development Project Proposal: The Daily Grind Cafe

## 1. Competitor Analysis & Market Research
- **Local Competitor A (Starbucks SA):** Strong brand presence, but lacks local community feel and direct artisanal ethical sourcing details.
- **Local Competitor B (Truth Coffee Roasting):** High-end branding, but desktop layout navigation is overly complex for quick menu browsing.
- **Our Value Proposition:** The Daily Grind Cafe offers a clean, accessible layout focused on fast menu discovery, clear enquiry forms, and transparent ethical coffee origin information.

## 3. Design System & Wireframes

### Color Palette & Typography
- **Primary Brand Color:** `#3e2723` (Deep Coffee Brown)
- **Secondary Accent Color:** `#d7ccc8` (Warm Cream)
- **Background Fill:** `#f9f6f0` (Off-white Soft Canvas)
- **Heading Typography:** `Georgia, serif` (Classic & Artisanal)
- **Body Typography:** `'Segoe UI', sans-serif` (High Legibility)

### Wireframe Specifications
- **Desktop (1200px):** Multi-column grid layout, sticky horizontal header menu, side-by-side content blocks.
- **Tablet (768px):** 2-column simplified grid, relative scaling typography (`rem` units).
- **Mobile (375px):** Single-column stacked arrangement, full-width touch buttons, vertical collapsed navigation.

## 4. Technical Specifications & Features
- **Semantic HTML5:** Built using `<header>`, `<nav>`, `<main>`, `<article>`, `<fieldset>`, and `<footer>`.
- **CSS Architecture:** Responsive Flexbox and Grid modules, relative sizing units (`rem`, `%`), and custom CSS variable themes.
- **User Interactions:** Interactive element states using `:hover`, `:focus`, and `:active` CSS pseudo-classes.
- **Cross-Device Testing:** Tested across modern web browsers (Chrome, Edge, Firefox) using Google Chrome Developer Tools.
